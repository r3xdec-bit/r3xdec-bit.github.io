# r3xdec design — AI Agent Canvas Installation (`r3xdec.design/INSTALL.md`)

Connect your AI coding agent (Claude Code, Codex, OpenClaw, Hermes, Cursor, Windsurf, Gemini CLI, OpenCode) to the **r3xdec design** canvas.

## 1. Install the r3xdec CLI

```bash
npm install -g @r3xdec/cli
```

## 2. Authenticate with your r3xdec design workspace

```bash
r3xdec login
```

## 3. Connect and generate on the canvas

```bash
r3xdec init --canvas
r3xdec design "Build a dark editorial landing page with custom design.md tokens"
```

## 4. Export design tokens (`design.md`) & production code

```bash
r3xdec export --format html,css,tailwind
```
