Common Questions

Can we deploy Nexus on-premise?

Yes. While we offer a managed cloud solution, our Enterprise tier supports full on-premise deployment via Docker containers or Kubernetes helm charts, ensuring data never leaves your infrastructure.

How does the pricing model scale?

Nexus uses a seat-based model for administrative users. API usage is billed based on volume tiers. We offer volume discounts for enterprise agreements with annual commitments.

Is there a dedicated support manager?

Enterprise plans include a dedicated Technical Account Manager (TAM) and 24/7 priority support with 1-hour SLA guarantees for critical incidents.
