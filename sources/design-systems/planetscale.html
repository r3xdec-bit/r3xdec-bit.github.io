The database platform
that reads like a terminal.

Terminal Ledger is a plain-text, developer-console aesthetic: one monospace face at one size, hairline rules where others reach for shadow, and color rationed to exactly two buttons and the links you're meant to follow. Everything is a document. Nothing is decoration.

Surface & depth

There is no elevation ladder. Depth is a border decision: hairline, dashed frame, or a single left rule. Radius is 0 everywhere; the pill token is reserved and unused on real surfaces.

Hairline card

1px solid #414141 doing the work a shadow would do elsewhere.

radius 0 · border 1px · no shadow

Dashed frame

The heavier container voice — footers, diagram nodes, callouts.

radius 0 · border 2px dashed · no shadow

Left-rule block

The lightest container: a single vertical hairline and 16px of indent.

radius 0 · border-left 1px · pad-left 16
Motion

One curve, one duration. Motion makes discrete state changes feel instant — no stagger, no scroll reveals, no spring.

state
background-color · 0.15s · cubic-bezier(0.4, 0, 0.2, 1)
hover
all · 0.15s · ease-out-leaning · state changes only
